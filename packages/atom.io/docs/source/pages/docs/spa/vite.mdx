## compiler options

The plugin compiles .tsx and .jsx files by default, including files referenced with Vite query parameters. Its optional include RegExp selects a narrower set of component files. Files inside node_modules are excluded.

The compiler preserves reactive JSX expressions, live component props, and spread precedence. A standard TypeScript JSX transform alone does not preserve those behaviors, so keep this plugin enabled in development and production.

## development

Component-only JSX modules use hot replacement. An edit reruns affected DOM and scene roots against their original stores, including separate hydrated and client-only Astro islands. Atom values, persistent family members, and timeline history survive. Old scopes release subscriptions, refs, listeners, and onCleanup callbacks exactly once; DOM-local values and family members disposed by component cleanup reset. A hot setup failure shows an error and retains the store for the next edit. Production builds contain no hot registration.

Keep state definitions and store factories in separate modules from component-only views. State-definition edits, mixed runtime exports, re-exports, changed export boundaries, and top-level side effects fall back to full reloads. Type-only exports are allowed. This first implementation refreshes the whole affected root.
