# <low-emphasis>@atom.io</low-emphasis>/devtools

Inspect an atom.io store in a floating debugger. Ecology opens first and shows how atoms, selectors, and families connect. The other tabs show live atoms and selectors, recorded transactions, and undo/redo timelines.

Add the debugger and its SPA peer to an existing atom.io app.

## Embed Ecology

Import Ecology or mountEcology from @atom.io/devtools/ecology to put the live 3D graph, search, and editor directly on a page. Supply the store to inspect and load @atom.io/devtools/css once.

<Exhibit src="devtools/exhibits/mount-ecology.ts" />

## Edit state

Expand a JSON value to edit its children. Change a writable row’s type from its dropdown. Drag an array item’s handle to move it, or focus the handle and use Alt+Up or Alt+Down.

Ecology shows cached values and offers Generate for state that hasn’t been read. Use its search to filter the graph and editor by key, family, or runtime type.

## Try it here

Press Ctrl+Shift+A to show the debugger on atom.io.fyi. Click the orbital logo if the panel is minimized. The debugger remembers its visibility, window layout, and last selected tab.

## Migrate from older devtools

The SPA devtools and React devtools packages are deprecated. Install the shared debugger above and update your component and stylesheet imports to match your framework’s example. The old React package’s standalone JSON editor, elastic input, error boundary, and customization exports have no equivalents in the shared package.
