# @atom.io/eslint-plugin

ESLint rules for atom.io state and transaction declarations.

Install this package as a development dependency alongside ESLint 9 or later and `@typescript-eslint/parser` version 8. The package installs its typescript-eslint utilities transitively.

See the [setup, migration guide, and rule examples](https://atom.io.fyi/docs/eslint-plugin). Existing `atom.io/eslint-plugin` users can switch the import to `@atom.io/eslint-plugin` without changing rule names or options.
