## compiler options

The plugin compiles .tsx and .jsx files by default, including files referenced with Vite query parameters. Its optional include RegExp selects a narrower set of component files. Files inside node_modules are excluded.

The compiler preserves reactive JSX expressions, live component props, and spread precedence. A standard TypeScript JSX transform alone does not preserve those behaviors, so keep this plugin enabled in development and production.

## development

SPA uses full page reloads when a matching component changes. The plugin deduplicates SPA and atom.io and keeps their runtime entrypoints out of dependency prebundling so renderers, hooks, and stores share one runtime.
